# Riptober
A site for documenting Ripping Resources' yearly Riptober event

## What is Riptober?
> this is essentially Inktober but with rips instead of art.
> For those who don't know what this would be, every day I will provide a word which you can make a rip based on.
> The best rips for each word will be judged by us, and if you manage to make a rip for every cue in time then you will recieve a special role
> Rips made for this don't need to be super-high quality, so it's purely for fun.
> [However if a rip is considerably effortless, already been published or generated using sites such as rave.dj, you may be disqualified and not be able to gain the 100% completion role.]"

\- Navag8r October 1st, 2020
